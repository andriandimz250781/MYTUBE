# **App Name**: ANDTUBE

## Core Features:

- Video Upload: Allow users to upload video files from various devices (desktop, mobile, tablet).
- Video Playback: Enable smooth video playback across different browsers and devices.
- Search and Discovery: Implement a search bar to find videos, channels, and playlists.
- Channel Creation: Let users create and manage their own channels, including customization options.
- Watch History: Keep track of viewed videos for easy revisiting.
- AI-Powered Tagging: Automatically generate relevant tags for uploaded videos using an AI tool for content understanding. Tags can be manually overridden or appended by users.
- Responsive Layout: Ensure a consistent user experience across desktop, mobile, and tablet browsers with responsive design.

## Style Guidelines:

- Primary color: Deep Blue (#1E3A8A), for a professional and trustworthy feel, similar to established platforms.
- Background color: Very light gray (#F9FAFB), providing a clean and modern backdrop that focuses attention on the content.
- Accent color: Vivid Orange (#EA580C) to highlight calls to action and interactive elements.
- Body and headline font: 'Inter' (sans-serif) provides a clean, modern and highly readable interface.
- Use a consistent set of line icons for key actions (play, pause, upload, search). Favor a modern, minimalist aesthetic.
- Implement a grid-based layout for video thumbnails. Display related content using a horizontal carousel.
- Use subtle transitions and animations (e.g., fade-in effects) when loading videos or navigating between pages to enhance the user experience.
